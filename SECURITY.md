# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| v2.2.0  | :white_check_mark: |
| < 2.2.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it by emailing oleymcclure@gmail.com.

Please include a description of the issue and steps to reproduce it. You can expect an initial response within 48 hours.
